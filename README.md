# 发票报销与整理工具

这是一个面向 Windows 的离线发票处理程序，用于读取 PDF 发票、检查报销问题、生成报销清单，以及按金额整理发票。程序提供图形界面，不需要账号、网络或数据库。

## 主要功能

- 报销清单模式：从 PDF 提取发票号码、品名和价税合计，按模板生成 Excel，并按最终品名重命名发票。
- 整理排列模式：按含税金额排序和分组复制发票，同时生成整理清单，不修改原始 PDF。
- 支持把 PDF 从资源管理器拖入列表。
- 支持材料、办公和设备三种报销经费类型，默认为材料。
- 自动标记购买方为个人、单位为批或报销类型不符的发票。
- 一键处理红色问题发票：先复制到“存在问题的发票”子文件夹，逐一核对文件大小和 SHA-256，再把原文件送入 Windows 回收站。
- 500 元至 2000 元以内的发票提示需要支付凭证，超过 2000 元的发票提示需要公对公转账。
- 自动清理项目名称、规格型号、重复文字、价外费用和方括号备注。
- 品名与 PDF 文件名主体最多 60 个字符，超出部分以“等”替代；同名文件使用下划线加数字编号。
- 默认不读取子文件夹，可在界面中手动启用。

## 直接使用

1. 从 GitHub Releases 下载“报销工具.zip”。
2. 完整解压 ZIP，不要只复制单个 EXE，也不要删除程序目录中的“_internal”文件夹。
3. 双击“发票报销工具.exe”。
4. 选择工作模式和发票文件夹，检查识别结果后执行导出或整理。

发行版适用于 64 位 Windows 10 和 Windows 11。使用发行版不需要安装 Python，也不要求安装 Microsoft Excel。

## 报销清单模式

每张发票在 Excel 中占一行，数量固定为 1，单价与总价都使用发票“价税合计”中小写金额后的数字。姓名、学号和备注留空。

红色发票不会写入 Excel，也不会在导出时重命名。使用“一键移除标红”后，程序会创建或复用“存在问题的发票”子文件夹。只有全部副本校验通过，原文件才会送入 Windows 回收站；失败的原文件保留在原位置。

详细规则见“使用说明.txt”。

## 从源码运行

安装 Python 3.11 或更高版本，然后在项目目录运行：

```powershell
python invoice_app.py
```

Windows Python 3.13.0 存在 Tkinter 打包问题，请使用 3.13.1 或更高版本。

## 运行测试

```powershell
python -m unittest discover -s tests -v
```

真实发票样本不提交到仓库。缺少本地样本目录时，对应的样本测试会跳过。

## 重新打包

```powershell
powershell -ExecutionPolicy Bypass -File .\build_release.ps1
```

构建脚本会在项目内创建隔离环境并生成“报销工具”文件夹和“报销工具.zip”。构建目录、发行包和额外 Excel 文件由 Git 忽略；仓库只保留源码、测试、模板和说明。

## 项目文件

- `invoice_app.py`：图形界面和两种模式的入口。
- `invoice_core.py`：发票解析、品名处理、风险检查和文件操作。
- `invoice_sorter.py`：按金额整理和排列功能。
- `template_export.py`：按照模板生成 Excel。
- `报销清单表.xlsx`：唯一纳入版本控制的 Excel 模板。
- `使用说明.txt`：完整操作方法和业务规则。
- `build_release.ps1`：Windows 打包脚本。
- `发票报销工具.spec`：PyInstaller 构建配置。
- `tests`：自动化测试。

## 数据处理

程序在本机离线处理发票，不上传 PDF 内容。OCR 模型随发行包提供，扫描件识别不依赖在线服务。
