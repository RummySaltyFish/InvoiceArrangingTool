使用方法
1. 双击“发票报销工具.exe”。
2. 在窗口顶部选择“报销清单”或“按金额整理和排列”。两种模式各自保留独立的列表和操作，不会混用处理规则。
3. 报销清单模式启动时不显示文件夹。点击“选择文件夹并读取”，选中后显示对应路径。每次启动默认不包含子文件夹，需要时手动勾选。
4. 也可把一个或多个 PDF 从资源管理器直接拖到窗口。尚未选择文件夹时，以第一份 PDF 所在文件夹作为读取文件夹；拖入其他文件夹的 PDF 时，确认导出后会复制到读取文件夹并按品名命名，原文件保留。
5. 选择报销经费类型：材料、办公或设备，默认为材料。切换类型会立即重新检查并排序列表。
6. 在列表中查看品名，双击行或点击“修改品名”可自定义，再点击“确认品名”。列表同时显示导出后的 PDF 文件名。
7. 全部确认后点击窗口顶部右侧的“确认并导出”，选择表格保存位置，统一导出并处理 PDF。

按金额整理和排列模式
该模式用于按发票的含税总价排列和分组，不生成报销清单，也不修改原 PDF。
选择发票文件夹和输出文件夹后点击“读取并预览”；也可把 PDF 直接拖入当前模式的列表。默认不读取子文件夹。
默认按金额从小到大排列；勾选“金额从大到小”可反向排列。默认每组最多 15 张，可输入其他正整数。
金额小于 500 元与金额大于等于 500 元的发票不会放入同一个分组文件夹；不足一组时，另一金额区间从新组开始。
默认在复制后的文件名前添加全局排序序号和金额。原始 PDF 始终保留，整理结果复制到输出文件夹。
无法识别含税总价的 PDF 复制到“999_未识别金额”文件夹。输出文件夹同时生成“发票整理清单.csv”，记录顺序、分组、金额、原文件和整理后路径。

问题检查与颜色
红色、白字表示无法报销：购买方为个人、明细单位为“批”，或品名与所选报销类型不符。红色发票始终排在最上面。
办公类包括打印纸、笔、图书以及打印机墨盒、碳粉、硒鼓；设备类包括电脑整机、3D 打印机整机等整机设备；其余按材料判断。
金额大于 2000 元显示蓝色、白字，排在红色后面，并提示“需要公对公转账”。金额大于等于 500 元且小于 2000 元显示黄色，并提示“需要支付凭证”。这两类正常导出。
列表顺序为红色、蓝色、黄色、其他待处理、正常白色。
“一键移除标红”会在当前读取文件夹下创建或复用“存在问题的发票”子文件夹。程序先把所有红色发票逐一复制到该文件夹，以文件大小和 SHA-256 校验副本与原件完全一致；全部校验通过后，才把原文件送入 Windows 回收站并从当前清单移除。已有子文件夹和其中的文件不会删除或覆盖，同名文件自动增加“_数字”编号。
操作完成后会提示问题文件夹位置和回收站还原方法。复制或校验失败时原件保留在原位置；也可右键选中的红色行并选择“取消标红”，需要时再次右键恢复自动标红。
确认导出时会再次提示：红色发票不写入 Excel，也不复制或重命名对应 PDF。

导出规则
每张发票一行，数量始终固定为 1，单价和总价一致。
金额只读取“价税合计”一行中“（小写）”后的数字，不读取明细单价、明细数量或其他合计。
按照模板的姓名、学号、发票号码、品名、单价、数量、总价、备注顺序输出。
姓名、学号、备注全部留空，不提供输入框，也不从发票或历史设置读取。
去掉项目名称开头的 *分类*，拼接换行，简化重复文字，再结合对应的规格型号。
自动品名由项目名称和规格型号直接组合，例如“螺钉M4×35”。同一项目的不同规格去重合并。
品名不限制为 9 个字符，保留按规则清理后的完整项目名称和规格型号。
品名及 PDF 文件名的主体最多 60 个字符，重复文件编号不计入主体长度。超出部分以“等”替代。
长品名优先按标点分段：如果加入两个标点之间的下一段会使累计内容超过 50 个字符，则从该段前的标点处省略并追加“等”，避免截断连贯内容；没有合适分段点时才在 60 个字符内截断。
删除“价外费用”；删除中文或英文方括号及其中的文字；“+”或“＋”统一替换为“和”。
项目名称和规格型号直接连接，不使用圆括号，例如“锂电池18650”。
项目名称为“单片机”“电子元件”或“电子元器件”且规格型号含中文时，只使用规格型号作为品名。
项目名称含“螺钉”或“螺栓”时，规格中只保留字母、数字和“×”尺寸标记；规格过多时最多保留两个，其他以“等”省略。
规格型号中只要包含“/”（包括全角“／”），该项规格就不加入品名，例如“0.9kg/组”。
规格型号中的尺寸符号“*”显示为“×”，便于品名和文件名保持一致。
规格开头重复的项目名称只保留一次；无规格时只保留清理后的项目名称。
重复号码且名称、金额一致的发票只保留一次，可点击“重复文件”查看跳过情况。
发票号码作为文本写入，保留长号码和前导零。

文件重命名
读取文件夹内的 PDF 重命名为最终品名，例如“螺母.pdf”。从其他位置拖入的 PDF 复制到读取文件夹并按同一规则命名，外部原文件保留。
品名允许重复。完全相同的品名在清单中保持不变，对应 PDF 文件名以“_数字”增加编号，例如两行品名都为“螺母”，PDF 为“螺母.pdf”和“螺母_2.pdf”。编号不计入 60 字主体上限。
除上述重名编号外，表格品名与对应 PDF 去掉扩展名后的文件名一致。读取和修改时只预览，点击“确认并导出”并选定保存位置后才执行。
取消保存不会重命名文件。再次导出不会重复追加序号。
文件名禁用符号先在品名中统一替换：“*”替换为“×”，其余替换为对应全角符号。结尾句点和空格去除，过长的名称缩短，系统保留名称加前缀下划线。
被移出清单的发票、未进入清单的重复副本保持原文件名，可在“重复文件”中查看保留的对应文件。
PDF 全部重命名或复制成功后才发布表格；若出错，则不发布新表格，并恢复本次已改名的文件、删除本次复制的副本。恢复失败时会列出原因。

补填与修改
双击表格行可修改发票号码、品名和含税合计。
“待处理”表示缺少字段、无法识别唯一的小写含税合计或文件无法读取，需要补填或移出本次清单后导出。
“查看原发票”打开选中的原始文件；“移出本次清单”仅移出当前列表，不删除 PDF。
每个 PDF 应对应一张发票，可以包含多页；一个 PDF 内有多个发票号码时需要先拆分。
电子发票读取内嵌文字，扫描件使用内置的本地识别模型。

搬到其他电脑
解压“报销工具.zip”，复制整个“报销工具”文件夹即可使用；双击其中的“发票报销工具.exe”。
不要单独复制 EXE，也不要删除同目录下的“_internal”文件夹；程序、模板和本地识别模型需要作为一个完整文件夹使用。
不需要安装 Python，不需要账号或网络，也不要求安装 Excel 才能导出。
适用于 64 位 Windows 10/11。
若要调整模板格式，将“报销清单表.xlsx”放在程序旁边；表头名称与顺序保持不变。
上次选择的文件夹保存在程序旁的“报销工具设置.json”，仅用于下次选择文件夹时定位；启动后不自动显示或读取。“包含子文件夹”每次启动都默认为关闭。

源码重新打包
安装 Python 3.11 以上版本，但不要使用 Windows Python 3.13.0；该版本存在 Tkinter 打包缺陷，应升级到 3.13.1 以上。
在项目目录中运行“powershell -ExecutionPolicy Bypass -File .\build_release.ps1”。脚本会在项目内建立隔离环境、安装 requirements-build.txt 中的依赖，并重新生成“报销工具”文件夹和“报销工具.zip”。
构建目录、虚拟环境、成品文件夹和 ZIP 均由 .gitignore 排除，不会进入源码仓库。
